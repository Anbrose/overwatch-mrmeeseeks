# 一起看电视直播 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `@mrmeeseeks 一起看 <台名>` opens a synced watch room playing a Chinese TV channel live, with the stream relayed through our server, candidate sources merged from several public m3u lists, periodic probing, and automatic/manual source switching.

**Architecture:** Four new modules:
- `tv_net.py`: an SSRF-safe HTTP fetch layer.
- `tv_channels.py`: m3u parsing, name normalization, aliases, the channel table, matching, persistence, and the 6-hour refresh.
- `tv_stream.py`: variant choice, the H.265 check, and the probe.
- `tv_relay.py`: per-(room, version) live playlist rewriting, the segment map and cache, and dead-stream detection.

Changes to existing code:
- `watch_rooms.py` gains a `tv` video kind with its own room limit.
- `watch_server.py` serves `/tv/{room}/{version}/index.m3u8` and `/tv/{room}/{version}/s/{n}` and handles `tv_next`/`tv_stall`.
- `watch_ui.py`/`bot.py` route queries to channels and mix them into the existing select.
- `watch_web/` gets a live mode.

**Tech Stack:** Python 3.12, discord.py ≥ 2.6, aiohttp ≥ 3.9, hls.js 1.5.20 (cdnjs), plain-script tests run in Docker.

**Spec:** `docs/superpowers/specs/2026-10-30-watch-tv-design.md` (builds on `2026-10-23-watch-together-design.md` and `2026-10-24-watch-search-design.md`)

## Global Constraints

- **Running tests:** run every test file with `docker build -q -t mrmeeseeks:test . >/dev/null && docker run --rm -u root -v "$PWD":/repo -w /repo mrmeeseeks:test python tests/<file>.py`. A pass means exit code 0 and no `FAIL` lines. Tests never touch the network: they use local aiohttp servers on 127.0.0.1 and fixtures in `tests/fixtures/tv/`. Those fixtures are already captured from the real lists; do not regenerate them.
- **Test style:** plain scripts with `check(name, cond)` and an `if __name__ == "__main__":` runner, like `tests/test_watch_server.py`.
- **Dependencies:** no new Python dependencies.
- **Outbound requests:** every request our server makes for TV goes through `tv_net.open_url` and passes its `ip_allowed` check on every hop. The production default is `is_public_ip`. Tests pass `ip_allowed=lambda ip: ip == "127.0.0.1"`; no other bypass exists.
- **What our server may fetch:**
  - the URLs in the `WATCH_TV_LISTS` lists;
  - the candidate URLs from the channel table;
  - URLs that appear inside a playlist fetched from one of those candidates.

  Never a URL supplied by a client.
- **Env:**
  - `WATCH_TV_LISTS`: comma-separated URLs. Unset means the default `https://raw.githubusercontent.com/Guovin/iptv-api/gd/output/ipv4/result.m3u,https://raw.githubusercontent.com/iptv-org/iptv/master/streams/cn.m3u,https://raw.githubusercontent.com/suxuang/myIPTV/main/ipv4.m3u`. Set to an empty string to disable TV.
  - `WATCH_MAX_TV_ROOMS`: default `2`.
  - State file: `STATE_DIR/tv_channels.json`.
- **Numbers (exact):**

## Review Focus

1. **Messy real-world m3u files:** BOM, CRLF line endings, no `#EXTM3U` header, `#EXTVLCOPT` lines between `#EXTINF` and the URL, commented-out URL lines (`#http…`) → parsed exactly like the clean case. (Test in Task 2.)
2. **Upstream playlist shapes:** a mix of absolute URLs, relative URLs, root-relative URLs and segments on a different host, plus an `EXT-X-KEY URI=` → the playlist sent to the browser contains no upstream host at all, only `/tv/...` paths. (Test in Task 4.)
3. **Segment requests that don't belong:** a segment id from an old version, from another room, or never issued → 404, and the upstream receives zero requests. (Test in Task 4 and Task 6.)
4. **Two viewers send `tv_stall` at the same moment:** or a stall races the host's `tv_next` → exactly one switch happens, and the version goes up by one. (Test in Task 6.)
5. **Bad state file:** `tv_channels.json` is missing, empty or corrupt → the table starts empty, the bot keeps working, and the refresh fills the table. (Test in Task 2.)

### Task 1: SSRF-safe fetching (`tv_net.py`)

**Files:**
- Create: `server/tv_net.py`
- Test: `tests/test_tv_net.py`

**Interfaces:**
- Produces:
  ```python
  class Blocked(Exception): ...            # disallowed scheme / address / too many redirects
  class TooLarge(Exception): ...
  def is_public_ip(ip: str) -> bool        # ipaddress.ip_address(ip).is_global and not multicast; IPv4-mapped IPv6 checked as IPv4
  def quote_url(url: str) -> str           # percent-encode non-ASCII and spaces in path/query; leaves existing %xx alone
  class FilteringResolver(aiohttp.abc.AbstractResolver):
      def __init__(self, ip_allowed: Callable[[str], bool], inner: aiohttp.abc.AbstractResolver | None = None)  # inner default aiohttp.DefaultResolver()
      # resolve(): drops records whose host fails ip_allowed; none left -> raise OSError("blocked address")
  def make_session(ip_allowed: Callable[[str], bool] = is_public_ip) -> aiohttp.ClientSession   # TCPConnector(resolver=FilteringResolver(...), ttl_dns_cache=60)
  async def open_url(session: aiohttp.ClientSession, url: str, ua: str | None, *,
                     ip_allowed: Callable[[str], bool] = is_public_ip,
                     timeout: float = 8.0, max_redirects: int = 5) -> aiohttp.ClientResponse
      # quote_url first; scheme must be http/https; literal-IP hosts checked with ip_allowed before each hop;
      # allow_redirects=False and follows 301/302/303/307/308 itself (Location resolved against the current URL);
      # UA header = ua or live_watch.USER_AGENT; returns the final response (caller releases); resp.url is the final URL.
  async def read_capped(resp: aiohttp.ClientResponse, cap: int) -> bytes   # iter_chunked; raises TooLarge past cap
  ```
  Why both checks: aiohttp skips the resolver for literal-IP hosts, so `open_url` checks literal IPs itself. The resolver covers hostnames, including hostnames reached through a redirect.

### Task 2: Channel table (`tv_channels.py`)

**Files:**
- Create: `server/tv_channels.py`
- Test: `tests/test_tv_channels.py`

**Interfaces:**
- Consumes: Task 1 `open_url`, `read_capped`, `make_session`, `is_public_ip`.
- Produces:
  ```python
  DEFAULT_TV_LISTS: str            # the exact default from Global Constraints
  REFRESH_SECONDS = 6 * 3600
  MAX_LIST_BYTES = 10 * 1024 * 1024
  @dataclass class Entry: name: str; tvg_name: str | None; group: str | None; ua: str | None; url: str; list_index: int
  @dataclass class Candidate:
      url: str; ua: str | None; list_index: int; is_4k: bool
      ok: bool | None = None        # None = never probed
      checked_at: float | None = None
  @dataclass class Channel:
      key: str                       # normalize_name() of the canonical name
      name: str                      # display name
      candidates: list[Candidate]
      @property must_have -> bool    # key endswith "卫视" or key startswith "CCTV"
      @property all_failed -> bool   # candidates non-empty and every ok is False
      def ordered() -> list[Candidate]   # see ordering rule
  @dataclass class Match: exact: Channel | None; partial: list[Channel]
  def parse_sources_env(raw: str | None) -> list[str]       # None -> DEFAULT split; "" -> []
  def parse_m3u(text: str, list_index: int) -> list[Entry]
  def normalize_name(s: str) -> str
  def canonical_key(name: str) -> str        # alias table applied after normalize_name
  def build_channels(entries: list[Entry], previous: dict[str, Candidate] | None = None) -> dict[str, Channel]
  class ChannelTable:
      def __init__(self, path: Path | None, lists: list[str], prober: Callable[[Candidate], Awaitable[bool]],
                   session_factory: Callable[[], aiohttp.ClientSession] = make_session,
                   ip_allowed: Callable[[str], bool] = is_public_ip, clock: Callable[[], float] = time.time)
      channels: dict[str, Channel]
      def match(self, query: str) -> Match
      async def refresh(self) -> None        # download lists, rebuild (keeping probe results by url), save, probe all, save
      async def run(self) -> None            # refresh at once, then every REFRESH_SECONDS; logs and keeps going on errors
  ```
  - The prober is injected. In production it is `functools.partial(tv_stream.probe, session, ip_allowed=...)` from Task 3. Tests pass a fake.

- **Parsing rules:**
  - Strip the BOM and accept CRLF line endings. The `#EXTM3U` header is optional.
  - For each `#EXTINF` line, the name is the text after the last comma, stripped. Also read `tvg-name`, `group-title` and `http-user-agent`.
  - The URL is the next line that does not start with `#`; skip `#EXTVLCOPT`/`#KODIPROP`/other `#` lines in between. Hitting another `#EXTINF` first means that entry has no URL. A commented `#http…` line is just a skipped `#` line.
  - Keep only `http://`/`https://` URLs. Drop any URL whose host is an IPv6 literal (`[` in the netloc).
- **`normalize_name`, applied in this order:**
  1. NFKC.
  2. Remove bracketed parts `(...)`, `[...]`, `（...）`, `【...】`.
  3. Remove whitespace, `-` and `_`.
  4. Uppercase.
  5. Repeatedly strip a trailing `高清|超清|标清|HD|FHD|UHD|4K|8K|频道`, except when the whole string is `CCTV4K`/`CCTV8K`.
  6. If it matches `^CCTV(\d{1,2})(\+)?`, collapse it to `CCTV<n>[+]`. For example, `CCTV1综合` → `CCTV1` and `CCTV5+体育赛事` → `CCTV5+`.
- **Alias table (`ALIASES: dict[str, str]`, normalized alias → canonical key):**
  - English names: `HUNANTV`→`湖南卫视`, `DRAGONTV`→`东方卫视`, `DRAGONTVINTERNATIONAL`→`东方卫视`, `ZHEJIANGTV`→`浙江卫视`, `ZHEJIANGTVINTERNATIONAL`→`浙江卫视`, `JIANGSUTV`→`江苏卫视`, `BRTV北京卫视`→`北京卫视`, `SHENZHENSATELLITETV`→`深圳卫视`.
  - Nicknames: `芒果台`→`湖南卫视`, `央视一套`/`中央一套`→`CCTV1`, and so on through `央视十七套`/`中央十七套`→`CCTV17`.
  - Province rule: for every channel whose key ends with `卫视` and prefix `P`, add the aliases `P` and `P台` (for example `湖南`, `湖南台`).
  - `canonical_key(n)` = `ALIASES.get(normalize_name(n), normalize_name(n))`.
  - The channel key comes from `canonical_key(tvg_name or name)`. If that gives an empty string, use the name.
- **Display name:** the canonical key itself when it came from the alias table or is CCTV/卫视. Otherwise the raw name that occurs most often, with its bracketed parts removed.
- **`is_4k`:** the raw name contains `4K` or `8K`, and the key is not `CCTV4K`/`CCTV8K`.
- **`ordered()`:**
  1. Groups in this order: `ok is True`, then `ok is None`, then `ok is False`.
  2. Inside each group, non-4K candidates come before 4K ones.
  3. After that, sort by `list_index`, then by the order of first appearance.
- **Merging:** the same URL in several lists counts once, keeping the lowest `list_index`. `previous` (keyed by URL) carries `ok`/`checked_at` over.
- **`match(query)`:**
  - `q = canonical_key(query)`. If `len(query.strip()) < 2`, return `Match(None, [])`.
  - `exact`: a channel whose key == `q`, or a province alias resolving to it.
  - Otherwise `partial`: channels where `q` is a substring of the key or of any of that channel's normalized aliases. English aliases are already uppercased, so this is case-insensitive. Exclude `all_failed` channels. Order must-have channels first, then shorter key, then key. Return at most 5.
  - Never match in the other direction (query contains key).
- **Persistence:** `tv_channels.json` is `{"updated_at": float, "channels": [{"key","name","candidates":[{"url","ua","list_index","is_4k","ok","checked_at"}]}]}`. Write it with a temp file and replace. If the file is missing, empty or corrupt → log a warning and start with `channels = {}`.
- **`refresh()`:**
  - Download each list with `open_url` + `read_capped(MAX_LIST_BYTES)` and decode as utf-8 with `errors="replace"`.
  - If a list fails, reuse that list's entries from the previous refresh, kept in memory as `self._last_entries[i]`. On the first run, skip it.
  - Rebuild the table and save. Then probe every candidate with concurrency 16 (`asyncio.Semaphore`), set `ok`/`checked_at`, and save again.
  - `match` sees the rebuilt table before probing finishes.

### Task 3: Variant choice and probe (`tv_stream.py`)

**Files:**
- Create: `server/tv_stream.py`
- Test: `tests/test_tv_stream.py`

**Interfaces:**
- Consumes: Task 1 (`open_url`, `read_capped`, `Blocked`, `TooLarge`, `is_public_ip`); Task 2 `Candidate`.
- Produces:
  ```python
  MAX_VIDEO_BPS = 8_000_000
  MIN_SEGMENT_BYTES = 1024
  MAX_PLAYLIST_BYTES = 2 * 1024 * 1024
  @dataclass class Variant: url: str; bandwidth: int | None; codecs: str | None
  class StreamError(Exception): ...
  def absolutize(ref: str, base: str) -> str        # urljoin; "//host/x" -> scheme of base
  def parse_master(text: str, base: str) -> list[Variant] | None   # None when no #EXT-X-STREAM-INF
  def choose_variant(variants: list[Variant]) -> Variant | None
  def media_sequence(text: str) -> int | None
  def segment_urls(text: str, base: str) -> list[str]
  def ts_has_hevc(data: bytes) -> bool
  async def resolve_media(session, url: str, ua: str | None, *, ip_allowed=is_public_ip) -> tuple[str, str]
      # (final media playlist URL, its text); follows at most 2 master levels; raises StreamError on non-#EXTM3U, no choosable variant, network error
  async def probe(session, cand: Candidate, *, ip_allowed=is_public_ip, timeout: float = 8.0) -> bool
      # resolve_media -> last segment -> >= MIN_SEGMENT_BYTES (read up to 64 KB) and not ts_has_hevc; any exception -> False
  ```
- **`choose_variant`:**
  1. Drop variants whose `codecs` contains `hvc1` or `hev1`.
  2. Among the rest that have a bandwidth ≤ `MAX_VIDEO_BPS`, return the highest.
  3. Else, if some variant has no bandwidth, return the first such one.
  4. Else return None.
- **`ts_has_hevc`:**
  - If the data doesn't start with sync byte `0x47` at 188-byte packet boundaries, return False.
  - Parse the PAT (PID 0) to find the PMT PID. Parse the PMT. Return True if any elementary `stream_type == 0x24`.
  - Honour `payload_unit_start_indicator`, the pointer field and the adaptation field.

### Task 4: Live relay (`tv_relay.py`)

**Files:**
- Create: `server/tv_relay.py`
- Test: `tests/test_tv_relay.py`

**Interfaces:**
- Consumes: Task 1 (`open_url`, `read_capped`, `is_public_ip`), Task 3 (`resolve_media`, `absolutize`, `media_sequence`, `StreamError`), Task 2 `Candidate`.
- Produces:
  ```python
  SEGMENT_CACHE = 12
  MAX_SEGMENT_BYTES = 20 * 1024 * 1024
  COALESCE_SECONDS = 1.0
  DEAD_SECONDS = 10.0
  MAX_SEGMENT_FAILURES = 3
  class LiveStream:
      def __init__(self, session, cand: Candidate, prefix: str, *, ip_allowed=is_public_ip, clock=time.monotonic)
          # prefix like "/tv/<room>/<version>"
      async def playlist(self) -> str          # rewritten media playlist; raises StreamError when upstream fails
      async def segment(self, n: int) -> tuple[bytes, str]   # (body, content type); KeyError for unknown n; StreamError on upstream failure
      dead_reason: str | None                  # set once dead; never cleared
  ```
- **`playlist()`:**
  - Within `COALESCE_SECONDS` of the last successful fetch, return the cached text. Concurrent callers share one in-flight fetch (`asyncio.Lock`).
  - Fetch the cached media URL. The first time, or after a failure, call `resolve_media(cand.url)` to get it again. That re-resolve is what refreshes IP-bound tokens.
  - Rewrite the playlist:
    - Every non-`#` line → `f"{prefix}/s/{n}"`.
    - Every `URI="…"` attribute in `#EXT-X-KEY`/`#EXT-X-MAP`/`#EXT-X-MEDIA` → `URI="{prefix}/s/{n}"`.
    - `n` comes from a per-stream `dict[absolute_url, int]`, counting up from 0. The same absolute URL always gets the same `n`.
    - Drop `#EXT-X-STREAM-INF`/`#EXT-X-I-FRAME-STREAM-INF` lines; they can't appear in a media playlist.
  - Keep the id map bounded: forget ids more than 200 below the newest.
- **Dead detection, evaluated inside `playlist()`/`segment()`:**
  - Upstream playlist failures continuously for ≥ `DEAD_SECONDS` since the last success, measured from the first failure → `dead_reason = "playlist"`.
  - `media_sequence` unchanged for ≥ `DEAD_SECONDS` while fetches succeed → `"stalled"`.
  - `MAX_SEGMENT_FAILURES` consecutive segment failures → `"segments"`. A successful segment resets the count.
- **`segment(n)`:**
  - Look up `n` in the id map; if it's missing → `KeyError`, with no upstream request.
  - Serve from an `OrderedDict` LRU of `SEGMENT_CACHE` entries.
  - Concurrent requests for the same `n` share one fetch.
  - Use `read_capped(MAX_SEGMENT_BYTES)`. Content type: the upstream `Content-Type`, or `video/mp2t`.

### Task 6: Serve and switch TV in the watch server (`watch_server.py`)

**Files:**
- Modify: `server/watch_server.py`
- Test: `tests/test_watch_server.py` (append)

**Interfaces:**
- Consumes: Tasks 1–5. `tv_stream.probe`, `tv_relay.LiveStream`, `TvInfo`, `tv_video`, `RoomManager.switch_tv`.
- Produces:
  ```python
  NO_TV_SOURCE = "这个台暂时没有能播的源"
  TV_SWITCHED = "已切换片源"
  TV_PREPARE_TIMEOUT = 20.0
  STALL_COOLDOWN = 15.0
  class TvUnavailable(Exception): message: str      # NO_TV_SOURCE
  WatchServer.__init__(..., tv_session_factory: Callable[[], aiohttp.ClientSession] = tv_net.make_session,
                       ip_allowed=tv_net.is_public_ip, tv_prepare_timeout: float = TV_PREPARE_TIMEOUT)
  async def WatchServer.prepare_tv(self, channel: Channel, order: list[Candidate] | None = None,
                                   start: int = 0, bad: set[int] = frozenset()) -> Video
      # order defaults to channel.ordered(); probes order[start], order[start+1], ... wrapping, skipping indexes in bad,
      # each at most once; first True -> tv_video(TvInfo(channel, order, i, set(bad))); none / timeout -> TvUnavailable
  ```
- **Routes:**
  - `GET /tv/{room_id}/{version}/index.m3u8` → `LiveStream.playlist()`, with `application/vnd.apple.mpegurl` and `Cache-Control: no-store`.
  - `GET /tv/{room_id}/{version}/s/{n}` → `LiveStream.segment(int(n))`.
  - Either route answers 404 when the room is unknown or not TV, the version isn't current, or `n` isn't an int / is unknown.
  - Upstream failure → 502.
  - After every call, if `stream.dead_reason` is set, start an auto switch for that (room, version). It runs in the background and is guarded by version.
  - Streams live in `self._tv_streams[(room_id, version)]`, created lazily from `room.video.tv.order[index]` with prefix `/tv/{room}/{version}`. `_evict` drops other versions and closed rooms.
  - One shared `aiohttp.ClientSession` from `tv_session_factory`, created lazily and closed in `_cleanup`.
- **State message:**
  - When `source == "tv"`: `video.hls = f"/tv/{room}/{version}/index.m3u8"`, `video.live = True`, `video.line_count = len(order)`, `video.line_index = index`.
  - `video.live` is False for everything else.
  - `position` is always 0 for TV.
- **WebSocket messages:**
  - `{"type":"tv_next"}`: host only → manual switch.
  - `{"type":"tv_stall","version":v}`: any present member; `v` must equal `room.version` → auto switch, but only if `now - room_last_switch >= STALL_COOLDOWN`. The time is per room, in `self._tv_last_switch[room_id]` (monotonic).
- **`_tv_switch(room_id, version, manual: bool)`:**
  - One in flight per room (`asyncio.Lock`, or drop if already running).
  - Auto:
    1. `bad = info.bad | {info.index}`.
    2. `prepare_tv(channel, info.order, start=info.index+1, bad=bad)`.
    3. If every index is bad → push `{"type":"error","message":NO_TV_SOURCE}` to all connections and stop.
  - Manual:
    1. `nxt = info.index + 1`.
    2. If `nxt == len(order)` → `nxt = 0` and `bad = set()`; otherwise `bad = info.bad`.
    3. `prepare_tv(..., start=nxt, bad=bad)`.
  - Then `rooms.switch_tv(room_id, version, video)`. On success, set `_tv_last_switch` and push `{"type":"notice","message":TV_SWITCHED}` to all of the room's connections.
  - A stale version → do nothing.
  - Manual `tv_next` with `len(order) == 1` → ignored.
